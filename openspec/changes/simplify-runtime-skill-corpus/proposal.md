## Why

The pre-change repository-owned runtime skills ship about 44,657 words that mix
unique judgment with duplicated lifecycle policy, deterministic mechanics,
historical test evidence, provider recipes, and model-obvious enforcement.
This change reduces runtime prompt volume for newer models while preserving
canonical authority boundaries and every behavior-bearing specialist contract.
The accepted disposable POC at `d620625` demonstrated 33 retained skills and
8,947 runtime words after retiring `compound`.

## What Changes

- Add automated `vitest-evals` coverage for assembled skills and rules before
  simplifying runtime instructions.
- Make `AGENTS.md` and `rules/` the shared lifecycle and policy owners; keep
  `SKILL.md` focused on triggers, unique judgment, output contracts, and
  escalation.
- Move deterministic validation into scripts and schemas, behavioral evidence
  into tests and fixtures, and provider procedures, templates, examples, and
  long methods into progressively loaded references.
- Give all 34 starting managed skills an explicit disposition, leaving 33
  retained runtime skills after `compound` retirement, without flattening Brainstorming,
  Start Project, Change Request Create, Nitro Review Feedback, OpenSpec Tasks,
  or the Plan, Execute, Review, and Finish modes into generic substitutes.
- Replace Security Review with read-only, evidence-backed threat analysis and
  remove provider mutation, fixed quotas, mandatory phase transcripts,
  speculative financial estimates, and generic compliance boilerplate.
- Regenerate all four explicit-only OpenSpec adapters from a compact lifecycle
  overlay owned by AX OpenSpec synchronization.
- Remove embedded Test Evidence and Validation/Verification history only after
  equivalent behavioral coverage exists.
- Keep prompt-size budgets as non-gating design pressure and report the
  resulting corpus metrics at integrated closure.
- Deliver the final implementation as 21 ordered, independently reviewable
  units after the complete disposable POC and post-POC topology review.

## Capabilities

### New Capabilities

- `agent-behavior-evals`: Automated, runner-neutral behavioral evaluation of
  assembled repository skills and rules with observable authority and
  specialist safeguards.
- `runtime-skill-corpus`: Canonical ownership, progressive disclosure,
  disposition, and preserved behavior requirements for the managed skill
  corpus.

### Modified Capabilities

- `ax-openspec`: Generated OpenSpec adapters gain repository lifecycle overlays
  and deterministic convergence validation from their generator.

## Impact

The change affects every managed `skills/*/SKILL.md`, selected references and
tests, the skill and charter validation surfaces, AX OpenSpec normalization,
the four generated `.agents/skills/openspec-*` adapters, `package.json`, and the
dependency lockfile. It adds Vitest 4 and `vitest-evals` as development
dependencies. It does not authorize provider mutation, merge, deployment, or
live AX synchronization from a feature branch.
