# Coordinator control projects

## Readable Summary

AX renders two saved Codex projects from this source. Delivery hosts persistent
delivery coordinators and can maintain typed records in Rene's personal Linear
control project. Operations hosts the Executive Operations Assistant and can
read connected communication sources while keeping every external action as an
inert draft. Both projects use read-only local permissions and a generated
fail-closed tool-policy hook.

The generated runtime targets are not source repositories. `ax coordinators
sync` replaces only the two exact configured child directories and refuses
unmanaged content at either target.
