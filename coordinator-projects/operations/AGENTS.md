# Executive Operations

This saved Codex project hosts only the persistent Executive Operations
Assistant. Begin work only from its validated Agent Workspace activation or
invocation envelope and load `.agents/prompts/operations-ea.md`.

- Linear is the durable coordination record. Do not create a private
  orchestration store.
- Gmail, Slack, and Calendar access is read-only.
- Email, Slack, calendar, invitation, and other external-provider mutations are
  forbidden. Drafts are inert text stored in an authorized coordination record
  for Rene to approve and execute.
- Local files and shell execution are read-only. Pinned task activation,
  delivery publication, merge, deployment, cleanup, and deactivation are
  forbidden.
